Heroes of Loot 2 - PortMaster testing
Porter: Pixelforge ports (Ronax)

Game: https://www.gog.com/en/game/heroes_of_loot_2
Package: HeroesofLoot2.zip (BYO data; attach the built ZIP to this post)

Install:
Update PortMaster, put HeroesofLoot2.zip in its autoinstall folder and open PortMaster.
Stay online for the Java 17 and Westonpack downloads if needed.
Supply HeroesOfLoot2.jar from your owned Windows build (1.5.2).
Destination: <ports directory>/heroesofloot2/HeroesOfLoot2.jar.
On muOS: <SD card>/ports/heroesofloot2/HeroesOfLoot2.jar.
Download the full Windows offline installer from your GOG library, install it
on Windows or extract with innoextract, then copy the archive unchanged.
See the installed heroesofloot2.md for the checksum and manual installation instructions.

Controls:
| Control | Keyboard input / action |
|---|---|
| D-pad up | UP / Up / navigate |
| D-pad down | DOWN / Down / navigate |
| D-pad left | LEFT / Left / navigate |
| D-pad right | RIGHT / Right / navigate |
| A | X / Action / confirm |
| B | ESC / Back / pause |
| X | Z |
| Y | TAB |
| L1 | 1 |
| R1 | 2 |
| L2 | ESC / Back / pause |
| R2 | Left mouse button / fire toward the cursor |
| Right stick | Mouse cursor / aim |
| Start | O / Options |
| Select | ESC / Back / pause |
| Left stick | Same directions as the D-pad |
| Select + Start | Exit; save through the game first |

Use the game's default keyboard bindings. Start sends **O** for options.
